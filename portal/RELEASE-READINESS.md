# جاهزية بوابة أمن المنشآت — 3 نوفمبر 2026

## قرار التشغيل

الوظائف الأساسية مناسبة لتجربة محدودة. ضُبطت روابط Supabase Auth وأكد المستخدم نجاح رسالة التأكيد وتسجيل الحساب. جاهزية استقبال أعداد كبيرة تبقى مرتبطة بسعة مزود البريد واختبار التحمل؛ لم يُنفذ اختبار تحمّل لمئات المستخدمين.

## ما أُكمل في هذا التحديث

| الجزء | التنفيذ والتحقق |
|---|---|
| حفظ النتائج | خدمة خادم وسجل خاص؛ لا تظهر رسالة الحفظ المؤكد دون إيصال ووقت استلام صالحين |
| التصحيح | الخادم يعيد حساب الدرجة من البنوك الحالية، ويرفض الأسئلة المكررة وغير المعروفة؛ لا يثق بالدرجة القادمة من المتصفح |
| تكرار الحفظ | إعادة نفس المحاولة تعيد الإيصال؛ تغيير الإجابات يرفض بـ409؛ واجهة إعادة الحفظ تدعم استعادة المحاولات المحلية |
| خصوصية النتائج | قراءة للقائد والمفوضين برئاسة الدورات فقط؛ الزائر يتلقى إيصال محاولته دون إتاحة سجل المتدربين |
| التفويض | مسؤوليات مستقلة لعدة أشخاص؛ قبول العضويات لا يسمح بتغيير الرتب أو توزيع الصلاحيات |
| التسليم | إشعار نجاح للمسؤولين ورابط إلى النتيجة نفسها؛ تأكيد التسليم يوثق هوية المنفذ ووقت الخادم ويحفظ التأكيد الأول |
| السرّي | القائد وحده يقرأ التقرير وPDF والمراجعات؛ جميع المسؤوليات المفوضة مجتمعة لا تمنح الوصول |
| الانتظار | 24 ساعة حسب الدورة ومعرف Discord، إضافة إلى القيد المحلي القديم؛ هوية الزائر نفسها غير موثقة |
| الشرطة | تجهيز تقرير التحقيق بالتنسيق السابق، نسخه، وملء إحالة للمجلس دون إرسال تلقائي |
| القضاء | فصل النشط والمنتهي والملغي، مع عرض نهاية المدة وسبب الإلغاء دون حذف أو تعديل الأرشيف القديم |
| المتابعة | فحص منشور للبوابة والأكاديمية، وصحة Auth وخدمة النتائج ومنع القراءة العامة |

## أدلة فعلية

- أعادت خدمة النتائج HTTP 200 مع إيصال `ACD-00000001` لبيانات اختبار اصطناعية. صحّح الخادم الإجابات إلى 100% رغم إرسال درجة محلية 0%.
- أعادت المحاولة المطابقة الإيصال نفسه، ورُفض تغيير إجاباتها بـ409. محاولة قراءة السجل بالمفتاح العام رُفضت بـ401.
- ظهرت النسخة في تبويب «أمن المنشآت» من جدول النتائج القديم، وطابقت الاسم الاختباري والدورة و10/10 و100%. مُسحت قيم صف الاختبار بعد التحقق، دون تغيير صفوف الأفراد.
- لم تُصدر خدمة Apps Script إيصالًا قابلًا للتحقق، لذلك تبقى نسخة الجدول «غير مؤكدة» في الواجهة؛ الحفظ الأساسي في البوابة مؤكد.
- نجح اختبار قاعدة البيانات داخل BEGIN/ROLLBACK: التكرار، منع تبديل الإجابات، انتظار 24 ساعة، قصر RPC الإدخال على الخدمة، ومنع عضو عادي من قراءة النتائج.
- نجحت تجربة بحسابي Auth اصطناعيين وجلسات كلمة مرور حقيقية: منع اعتماد الذات، منع التقرير قبل التفعيل، إرسال عادي وسري بعد التفعيل، رفع الملفات الخاصة وتأكيدها، منع العضو الآخر من القراءة والتنزيل، منع المرسل نفسه من قراءة/تنزيل السرّي، ومنع حذف التقرير بواسطة العضو.
- أُزيلت حسابات الاختبار وملفاتها وتقاريرها. التحقق اللاحق: لا حسابات QA ولا ملفات QA متبقية، وعدد الحسابات الأصلية محفوظ. نقطة QA أُعيد إغلاقها فورًا بـ410 خلف تحقق JWT.
- فُحصت الواجهة في المتصفح: تجهيز التحقيق والإحالة، عرض الأرشيف، واستعادة نتيجة محلية ثم عرض الدرجة والإيصال القادمين من الخادم.
- فحوص وحدات الخادم تغطي الدورات الست وحدود 70% و50%، البيانات غير الصالحة، الاستجابة الوهمية، التكرار، CORS، وحدود حجم الطلب.

الملف الذي استُخدم لاختبار Storage يفحص صلاحيات الرفع والتنزيل فقط. فحص إخراج PDF العربي البصري منفصل ضمن اختبارات المتصفح؛ لا تخلط الاختبارين.

## موانع التسجيل العام المتبقية

### روابط تأكيد البريد

تم ضبط Site URL وRedirect URLs، وأكد المستخدم نجاح التأكيد. تحقق الرجوع إلى البوابة وصفحة `portal/confirmed.html` نجح. عنوان رسالة تأكيد التسجيل باللغة العربية لم يتسنَّ تغييره عبر الأدوات المتصلة؛ لا يُعد ذلك منفذًا أمنيًا ولا مانعًا لتسجيل الحساب.

### SMTP الخاص بـAuth

ورد سابقًا خطأ `email rate limit exceeded`. إشعارات Resend الإدارية تعمل، لكنها لا تعني إعداد SMTP لتأكيد الحسابات. يلزم مزوّد ومرسل موثّق وتجربة فعلية قبل استقبال عدد كبير. حسابا QA أُنشئا مؤكدين لأغراض الاختبار، فلا يثبت نجاحهما وصول البريد. نجاح رسالة المستخدم اللاحق يثبت وصول تلك المحاولة، ولا يثبت سعة إرسال جماعية.

### الانتشار والنسخ الاحتياطي

لا تغيّر بيانات المواقع القديمة ولا تستورد أرشيف القضاء دون مراجعة. جرّب 3–5 أعضاء أولًا، ثم زد العدد مع مراقبة الأخطاء. رتّب نسخًا احتياطيًا مستقلاً قابلًا للاسترجاع؛ هذه الجولة لم تثبت استعادة نسخة احتياطية أو قياس حمل كبير.

## ملاحظات المراجعة الأمنية

الجداول `app_private` لا تملك RLS لكنها لا تمنح anon/authenticated صلاحيات استعمال المخطط أو قراءة/كتابة الجداول؛ تحذير اعتبارها مكشوفة تلقائيًا لا ينطبق بعد فحص المنح الفعلية. لا تُضف لها صلاحيات عميلة. تنبيهات `current_user_role` و`touch_updated_at` و`case_shares` تخص أجزاء أخرى من المشروع المشترك، ولم تُعدّل دون فحص اعتماد تلك التطبيقات عليها.
