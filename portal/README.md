# بوابة أمن المنشآت

بوابة عربية RTL لأغراض الرول بلاي. الرابط العام: https://muhamid9397827.github.io/rass-academy/portal/

## الحالة المؤكدة — 3 نوفمبر 2026

- الدورات عامة بدون حساب، والأنظمة الداخلية تتطلب حسابًا معتمدًا من القائد.
- التسجيل يحتاج تأكيد البريد وسبب تفعيل من 10 إلى 500 حرف. القائد وحده يعتمد الحساب أو يوقفه أو يغيّر رتبته.
- طلب التصريح لا يمنح صلاحية؛ القائد يقرر، ويُحفظ القرار ويصل إشعار للعضو.
- تقارير منظمة وحرة ومسودات وتصحيحات، مع إيصال من الخادم وPDF خاص وسجل مراجعات مؤرّخ.
- «سري للغاية» للقائد فقط: لا يستطيع المرسل قراءته أو تنزيله بعد الإرسال، ولا تشمل التفويضات هذا النوع.
- سلة محذوفات واستعادة وحذف نهائي بعد 30 يومًا، مع جدولة يومية وسجل عمليات.
- إشعارات لوحة القيادة والبريد تعمل؛ صف الانتظار يعيد محاولة الإشعارات المتأخرة كل دقيقتين. إعداد بريد **Auth** مسألة منفصلة موضحة أدناه.
- الشرطة: العقوبات الأصلية وتعديلات القيادة، وتجهيز ونسخ تقرير التحقيق بالتنسيق السابق واستخدامه في إحالة قضائية.
- القضاء: قضايا وقرارات وإنذارات؛ عرض النشط والأرشيف يفصل المنتهي والملغي، دون حذف السجلات القديمة أو نقلها تلقائيًا.

## نتائج الأكاديمية

`asf-academy-results` يحسب الدرجة من بنوك الأسئلة الحالية، ويحفظ النتيجة في `asf_academy_results` قبل تأكيد النجاح للمتدرّب. رقم الإيصال `ACD-…` ووقت الاستلام يصدران من الخادم. تكرار نفس المحاولة يعيد الإيصال نفسه، وتغيير إجاباتها يُرفض. إعادة الاختبار مقيدة بـ24 ساعة حسب Discord والدورة، مع حد لعدد النتائج الجديدة من المصدر نفسه.

- يظهر سجل النتائج والبحث والتصفح للقائد داخل صفحة «الدورات العامة».
- بيانات هوية الزائر مُصرَّح بها منه؛ لا تدّعي التحقق من ملكية حساب Discord، ولا تغيّر الرتبة تلقائيًا.
- نسخة Google Sheets القديمة تُرسل بعد الحفظ، مرة واحدة. HTTP 200 أو HTML لا يثبت حفظها؛ لا تُعلَّم «مؤكدة» إلا عند استجابة JSON ناجحة تعيد الإيصال نفسه.
- اختُبر وصول نتيجة اصطناعية إلى الجدول الفعلي، ثم مُسحت قيمة صف الاختبار فقط. هذا لا يُغيّر شرط تأكيد كل طلب على حدة.
- فشل النسخة الثانوية لا يُفقد النتيجة الأساسية. المحاولات غير المؤكدة يمكن إعادة حفظها من زر واضح، حتى بعد إغلاق الصفحة واستعادتها.

لا تتغير بنوك الأسئلة أو حدود النجاح السابقة: الدورات العادية 70%، وتأهيل الأفراد يحتفظ بحده السابق 50% وتوزيع الرتب المقترحة السابق.

## الملفات والتشغيل

- `app.js` واجهة الأعضاء والقيادة، و`workflow-tools.js` تنسيق التحقيق وحساب انتهاء الإنذار.
- `academy-app.js` واجهة الدورات، و`academy-config.js` توجيه النتائج إلى الخدمة الموثوقة.
- `supabase/migrations/20261103133918_academy_result_receipts.sql` إضافة سجل النتائج؛ مطبقة في المشروع الحالي. ثبّتها بعد ملفات SQL السابقة عند إعداد مشروع جديد.
- `supabase/functions/asf-academy-results/` خدمة النتائج. `verify_jwt=false` مقصود للدورات العامة؛ الإدخال إلى قاعدة البيانات محصور في خدمة الخادم، وRLS يمنع قراءة النتائج من الأعضاء والزوار.
- `build-academy-catalog.cjs` يولد مفاتيح التصحيح من بنوك الدورات. شغّله بعد تغيير الأسئلة؛ CI يرفض اختلاف النسخة المولدة.
- `live-auth-qa.ts` اختبار تشغيل يدوي فقط، لا يُنشر كخدمة دائمة. جرى تشغيله بحسابين اصطناعيين، ثم حذف الحسابين والتقارير والملفات وإعادة إغلاق نقطة الاختبار.

لا تضع مفاتيح `service_role` أو البريد أو كلمات المرور في GitHub أو المتصفح. `config.js` يحتوي مفتاحًا عامًا فقط. لا تُغيّر جداول التطبيقات الأخرى في المشروع المشترك.

## التحقق

فحوص Node: `academy-results.spec.mjs`، `workflow-tools.spec.cjs`، `purge.spec.cjs`، وفحوص الصحة للقراءة فقط `auth-health.spec.cjs` و`result-health.spec.cjs`.

`academy-results.database.sql` يختبر التكرار والتعارض والانتظار وصلاحيات النتائج داخل معاملة تنتهي بـROLLBACK. اختبارات Chromium في GitHub Actions تشمل التسجيل والتأكيد والاستعادة والتقارير وPDF والصلاحيات والتحقيق والأرشيف وحفظ النتائج والجوال.

## المتبقي قبل التسجيل المفتوح

1. ضبط Site URL وRedirect URLs من [لوحة Auth](https://supabase.com/dashboard/project/sxtbgnjbrcsmgsdhkbno/auth/url-configuration) ثم اختبار بريد جديد من رسالة التأكيد الأصلية. انظر `AUTH-CONFIRMATION-SETUP.md`.
2. تجهيز SMTP موثّق لبريد Auth وتجربة تسجيل حقيقي عبر بريد مختلف. نجاح Resend الإداري لا يثبت جاهزية بريد التسجيل.
3. اختبار تحميل تدريجي، وترتيب نسخ احتياطي مستقل قبل نشر الرابط على نطاق واسع. الاختبارات الوظيفية الحالية لا تثبت تحمّل مئات المستخدمين.
4. إذا أريد تأكيد آلي لكل نسخة في Google Sheets، يجب أن يعيد Apps Script إيصال المحاولة في استجابة JSON؛ النسخة الحالية لا توفر هذا الإثبات. سجل البوابة هو المرجع المؤكد حاليًا.

تفاصيل الأدلة والقيود في `RELEASE-READINESS.md`.
